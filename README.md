## 推荐使用流程

1. 先确定目标岗位和投递场景。
2. 从上方目录或分类选择接近的模板。
3. 进入模板详情页查看亮点、适用人群和示例内容。
4. 在 hicv.cn 在线套用模板，填写教育背景、实习经历、项目经历、技能证书和个人总结。
5. 结合岗位 JD 调整关键词、经历顺序和成果表达。
6. 导出前检查联系方式、时间线、格式完整度和 PDF 显示效果。
