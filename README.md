## 推荐使用流程

1. 先确定目标岗位和投递场景。
2. 从上方分类选择接近的模板。
3. 在线填写教育背景、实习经历、项目经历、技能证书和个人总结。
4. 结合岗位 JD 调整关键词、经历顺序和成果表达。
5. 导出前检查联系方式、时间线、格式完整度和 PDF 显示效果。

## 和写作指南配合使用

模板解决的是“结构和版式”，但投递效果更依赖内容质量。建议搭配 [resume-guide](https://github.com/HICV-CN/resume-guide) 查看：

- 简历经历怎么写清楚。
- 项目经历怎么突出结果。
- ATS 关键词怎么补。
- 校招和社招简历有什么差异。
- 投递前应该检查哪些细节。
