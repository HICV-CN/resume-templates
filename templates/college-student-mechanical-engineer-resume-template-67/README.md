## 模板亮点

- 聚焦机械工程师岗位，突出半导体制造与设备维护经历，体现良率分析与流程优化
- 项目经历围绕缺陷数据分析和点检流程优化，量化工具使用与改善成果
- 技能涵盖半导体制程、数据分析与机械设计基础，匹配制造业与机械工程方向
- 校园经历展示组织协调与动手实践能力，增强简历完整性

## 适用人群

本模板适用于机械工程专业大学生求职机械工程师实习或校招岗位，尤其适合半导体、电子制造、自动化设备等行业，帮助突出工艺分析、设备维护与数据驱动的改善能力。
