## 模板亮点

- 突出指标拆解、数据看板和业务复盘能力
- 适合呈现 SQL、Python、Excel 和 BI 工具经验
- 项目表达强调业务问题、分析方法和落地结果
- 版式清爽，方便 HR 快速定位核心技能

## 适用人群

适合正在准备首次实习投递的用户，尤其适合需要突出教育背景、实习项目、技能证书、校园经历和岗位关键词的人群。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书

## 示例内容摘要

| 模块 | 示例摘要 |
| --- | --- |
| 目标信息 | 实习生 / 2026届工商管理方向求职者 / 示例大学 / 工商管理 |
| 教育背景 | 主修工商管理相关课程，完成多门课程设计、项目实践和行业案例分析，围绕实习生方向持续积累专业技能、项目表达和岗位理解。 |
| 实习/工作经历 | 围绕首次实习投递场景参与资料整理、流程推进和结果复盘，协助团队完成需求拆解、信息收集、执行跟进和文档沉淀；结合实习生目标优化表达重点，形成可量化、可追踪的经历成果。 |
| 项目经历 | 基于 10 万级行为日志构建用户路径表，拆解首访、注册、激活和复访节点；使用 Python 完成异常值处理与 cohort 分析，识别低留存人群的关键行为差异；输出优化建议，包括新手引导、消…；设计交易、供给、活跃和品类四类指标，使用 BI 工具制作可视化看板；按时间、品类和价格带分析供需差异，帮助团队确定重点运营品类；整理指标字典和更新流程，提升后续迭代效率。 |
| 技能 | SQL、Python、Excel、Tableau/Power BI、A/B 测试、漏斗分析；指标体系、用户分层、留存分析、数据可视化、业务复盘 |
| 证书 | CET-6、统计软件应用证书 |
| 荣誉 | 全国大学生市场调查大赛省级二等奖；校级优秀毕业生 |
| 语言 | 英语 CET-6，能够阅读岗位资料和英文文档。 |
