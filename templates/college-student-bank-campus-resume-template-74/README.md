## 模板亮点

- 聚焦银行校招场景，突出金融专业背景与数据分析能力
- 实习经历与项目经验均围绕用户增长与留存分析，匹配银行零售业务需求
- 内容具体可量化，包含工具、指标与结果，便于面试官快速评估
- 避免通用模板，差异化展示个人在银行校招中的竞争力

## 适用人群

本模板适用于金融学及相关专业大学生，投递银行校招岗位（如零售业务、风险管理、数据分析方向），尤其适合有数据分析实习或项目经历、希望突出量化成果与业务理解的求职者。
