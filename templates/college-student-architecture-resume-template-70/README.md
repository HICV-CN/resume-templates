## 模板亮点

- 突出建筑设计核心技能：方案构思、建模、制图、渲染全流程覆盖
- 项目经历具体：包含场地分析、参数化设计、改造策略等真实任务
- 组织经历体现协作与沟通能力，适合团队型设计岗位
- 技能清单匹配建筑设计常用工具，可直接用于作品集展示

## 适用人群

本模板适用于建筑学及相关专业大学生求职建筑设计实习或初级岗位，尤其适合需要展示方案设计能力、软件熟练度和项目协作经验的应届生或在校生。
