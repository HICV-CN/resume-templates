## 模板亮点

- 突出试讲、实习教学和班级管理经历
- 适合展示教师资格证、普通话和教学竞赛成果
- 用教育场景语言组织项目与实践经历
- 结构稳重清晰，符合学校招聘阅读习惯

## 适用人群

适合正在准备大学生求职/实习 / 人工智能工程师的用户，尤其适合需要突出教育背景、实习项目、技能证书、校园经历和岗位关键词的人群。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书

| 实习/工作经历 | 围绕大学生求职/实习 / 人工智能工程师场景参与资料整理、流程推进和结果复盘，协助团队完成需求拆解、信息收集、执行跟进和文档沉淀；结合人工智能工程师目标优化表达重点，形成可量化、可追踪的经历… |
| 项目经历 | 围绕文本解读、问题链设计和课堂互动设计阅读课方案，完成教学目标、重难点、板书和评价方式设计；组织同伴试讲并收集反馈，迭代导入环节和提问层级，提升课堂节奏。；分析学生作文常见问题，设计素材积累、结构训练和互评反馈三个环节；整理优秀范文与修改建议，帮助学生形成可复用的写作框架。 |
