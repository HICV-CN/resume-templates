## 模板亮点

- 突出机器学习、模型训练和实验复盘能力
- 用项目指标和误差分析说明算法思维
- 适合算法实习、AI工程和校招投递
- 兼顾工程工具、数据处理和模型评估表达

## 适用人群

适合正在准备大学生求职/实习 / 算法工程师的用户，尤其适合需要突出教育背景、实习项目、技能证书、校园经历和岗位关键词的人群。

- 教育背景

- 专业技能
