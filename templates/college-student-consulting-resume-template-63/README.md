## 模板亮点

- 突出咨询顾问所需的结构化分析与问题拆解能力
- 强调用户调研与数据驱动的决策思维
- 展示跨团队协作与项目推进的实际经验
- 贴合大学生求职/实习场景，内容可复制、可量化

## 适用人群

本模板适用于经济学、管理学等商科背景的大学生，求职咨询顾问实习或校招岗位。内容围绕需求分析、调研执行、流程优化等咨询核心能力展开，帮助用户快速匹配咨询行业招聘要求。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书
