## 模板亮点

- 聚焦校招场景，突出实习与项目经历
- 模块化设计，清晰展示制程与设备技能
- 专业排版，符合半导体行业 HR 阅读习惯
- 强调良率分析与工程问题解决能力

## 适用人群

适合正在准备国企校招/社招的用户，尤其适合需要突出教育背景、实习项目、技能证书、校园经历和岗位关键词的人群。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书

## 示例内容摘要

| 模块 | 示例摘要 |
| --- | --- |
| 目标信息 | 国企求职者 / 2026届工商管理方向求职者 / 示例大学 / 工商管理 |
| 教育背景 | 主修工商管理相关课程，完成多门课程设计、项目实践和行业案例分析，围绕国企求职者方向持续积累专业技能、项目表达和岗位理解。 |
| 实习/工作经历 | 围绕国企校招/社招场景参与资料整理、流程推进和结果复盘，协助团队完成需求拆解、信息收集、执行跟进和文档沉淀；结合国企求职者目标优化表达重点，形成可量化、可追踪的经历成果。 |
| 项目经历 | 基于模拟晶圆检测数据建立缺陷分类表，按工序、批次、设备编号拆解异常来源；使用 Python 完成数据清洗、箱线图和 Pareto 图分析，定位关键波动参数；将分析结果转化为工艺检查清单，帮助…；梳理实验室真空镀膜设备的点检流程，补充开机前确认、运行中记录和关机后清洁三个阶段的检查项；设计维护记录模板，统一故障现象、处理动作和复测结果字段；通过流程可视化降低新成员上手成本，提升设备使… |
| 技能 | 半导体制程基础、设备点检、SOP 梳理、良率分析、异常复盘；Python 数据处理、Excel 透视表、Origin 绘图、电子电路基础、AutoCAD 基础 |
| 证书 | CET-6、计算机二级、电子工艺实训证书 |
| 荣誉 | 校级二等奖学金；电子设计竞赛校赛一等奖 |
