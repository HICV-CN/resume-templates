## 模板亮点

- 突出护理实习与项目经历，量化患者服务人次与干预效果
- 强调患者沟通与健康宣教能力，贴合护士岗位核心要求
- 展示急救与志愿服务经历，体现责任意识与团队协作
- 技能项覆盖临床操作与信息化工具，适配现代护理场景

## 适用人群

适用于护理学专业大学生求职护士岗位（实习/校招），尤其是希望进入综合医院、社区医院或专科医院从事临床护理工作的应届生。模板内容侧重护理操作、患者管理、健康教育与团队协作，帮助求职者突出专业能力与实践经验。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书
