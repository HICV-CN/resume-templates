## 模板亮点

- 突出需求分析、用户研究和原型设计能力
- 用项目数据和流程图呈现产品思维
- 适合产品经理实习、校招和转岗投递
- 模块结构覆盖项目、实习、技能和校园经历

## 适用人群

适合正在准备大学生求职/实习 / 产品经理的用户，尤其适合需要突出教育背景、实习项目、技能证书、校园经历和岗位关键词的人群。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书

## 示例内容摘要

| 模块 | 示例摘要 |
| --- | --- |
| 目标信息 | 产品经理 / 2026届工商管理方向求职者 / 示例大学 / 工商管理 |
| 教育背景 | 主修工商管理相关课程，完成多门课程设计、项目实践和行业案例分析，围绕产品经理方向持续积累专业技能、项目表达和岗位理解。 |
| 实习/工作经历 | 围绕大学生求职/实习 / 产品经理场景参与资料整理、流程推进和结果复盘，协助团队完成需求拆解、信息收集、执行跟进和文档沉淀；结合产品经理目标优化表达重点，形成可量化、可追踪的经历成果。 |
| 项目经历 | 围绕学生交易场景完成用户访谈、竞品拆解和需求优先级排序，输出用户旅程、核心流程图和PRD；定义发布商品、议价沟通、订单确认等关键路径，并用问卷验证功能优先级。；基于模拟漏斗数据定位注册、模板选择和导出环节流失点，提出默认模板推荐、填写进度提示和导出前检查清单；使用Figma完成低保真原型并组织同学可用性测试。 |
| 技能 | 用户访谈、竞品分析、需求文档、流程图、原型设计、数据看板；Figma、Axure、墨刀、Excel透视表、SQL基础、A/B测试基础 |
| 证书 | CET-6、计算机二级、产品经理课程项目证书 |
| 荣誉 | 互联网产品设计大赛校赛二等奖；校级优秀学生干部 |
| 语言 | 英语 CET-6，能够阅读岗位资料和英文文档。 |
