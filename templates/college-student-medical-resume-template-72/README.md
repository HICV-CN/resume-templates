## 模板亮点

- 突出临床见习与社区实践经历，体现医学生实际动手与患者沟通能力
- 项目经历聚焦慢性病管理与病例分析，展示科研思维与团队协作
- 社团组织经历强调义诊与健康宣教，契合医学生社会责任感
- 技能与证书覆盖临床操作、科研工具及英语能力，适配医院实习岗位

## 适用人群

适用于临床医学及相关专业本科生投递医院实习、规培或初级临床岗位。内容侧重基础诊疗能力、患者管理经验与科研素养，适合希望在医疗领域积累实践经验的医学生求职者。

## 包含模块

- 教育背景
- 实习经历

- 专业技能
- 荣誉证书

| 模块 | 示例摘要 |

| 目标信息 | 医学生 / 2026届临床医学方向求职者 / 示例医科大学 / 临床医学 |

| 实习/工作经历 | 协助带教医师完成每日门诊接诊，参与病史采集、体格检查及初步诊断，累计协助接诊患者约200人次。独立完成血压、血糖等常规检查操作，整理并归档患者健康档案150余份。参与社区慢性病管理随访工作，… |
| 项目经历 | 基于社区健康档案筛选60岁以上高血压患者120例，设计为期3个月的用药依从性干预方案。采用问卷调查与血压监测相结合的方式收集数据，使用SPSS进行统计分析，结果显示干预组血压控制率提升18%…；组织4人团队选取一例不典型心肌梗死病例进行深入分析，查阅国内外文献30余篇，从病理生理、诊断鉴别到治疗方案进行系统梳理。制作PPT并模拟临床查房汇报，获得院级病例分析竞赛二等奖。 |
| 技能 | 掌握病史采集、体格检查、无菌操作、换药拆线等临床基本技能；熟练使用电子病历系统及办公软件。；具备基础科研能力，能独立进行文献检索、数据整理与统计分析（SPSS）；通过英语六级，可阅读专业英文文献。 |
| 证书 | 大学英语六级证书；全国计算机等级考试二级（MS Office） |
