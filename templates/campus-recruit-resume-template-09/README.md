## 模板亮点

- 用产品方法组织经历，突出需求、方案、推进和结果
- 适合展示 Axure/Figma、PRD、数据分析和用户访谈
- 兼顾校园项目与互联网实习经历表达
- 右侧信息密度适中，便于面试官快速提问

## 适用人群

适合正在准备秋招/春招投递的用户，尤其适合需要突出教育背景、实习项目、技能证书、校园经历和岗位关键词的人群。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书

## 示例内容摘要

| 模块 | 示例摘要 |
| --- | --- |
| 目标信息 | 校招求职者 / 2026届软件工程方向求职者 / 示例科技大学 / 软件工程 |
| 教育背景 | 主修软件工程相关课程，完成多门课程设计、项目实践和行业案例分析，围绕校招求职者方向持续积累专业技能、项目表达和岗位理解。 |
| 实习/工作经历 | 围绕秋招/春招投递场景参与资料整理、流程推进和结果复盘，协助团队完成需求拆解、信息收集、执行跟进和文档沉淀；结合校招求职者目标优化表达重点，形成可量化、可追踪的经历成果。 |
| 项目经历 | 从学生组织报名效率低的问题出发，完成用户访谈、需求池整理和 MVP 范围定义；设计报名、审核、通知和签到流程，协调 4 名成员完成开发测试；上线试用覆盖 12 场活动，报名信息遗漏率明显下降。；拆解简历诊断场景中的结构完整度、岗位匹配度和表达清晰度指标，设计评分卡与修改建议模块；使用 Figma 完成高保真原型，组织 8 名同学进行可用性测试并迭代交互细节。 |
| 技能 | 用户调研、竞品分析、PRD、Axure/Figma、数据复盘、需求优先级；SQL 基础、Excel、流程图、跨团队沟通、版本管理 |
| 证书 | CET-6、PMP 项目管理基础课程结业 |
| 荣誉 | 互联网创新创业竞赛校级一等奖；校级优秀学生干部 |
| 语言 | 英语 CET-6，能够阅读岗位资料和英文文档。 |
