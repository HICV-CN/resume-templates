## 模板亮点

- 聚焦半导体工艺与器件测试，突出实验设计与数据分析能力
- 项目经历覆盖器件测试与TCAD仿真，体现理论与实践结合
- 实习经历包含工艺优化与良率提升，展示工程问题解决能力
- 社团组织经历体现技术传播与团队协作素养

适用于电子信息工程、微电子、集成电路等专业的大学生，求职半导体工程师实习或校招岗位，侧重工艺研发、器件测试或仿真方向，需要展示实验技能、项目成果与行业认知的求职者。
