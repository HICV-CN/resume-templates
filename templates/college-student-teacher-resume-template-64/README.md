## 模板亮点

- 聚焦教学实践：项目与实习经历均围绕课程设计、教学实施与效果评估，体现从理
- 数据驱动优化：擅长使用SPSS、Excel等工具分析教学数据，用量化结果
- 突出学生中心：强调分层教学、游戏化学习等差异化策略，展现对学生个体差异的
- 结构清晰实用：模块化布局，突出教育背景、实习、项目与技能，便于HR快速抓

## 适用人群

本模板适用于教育学、小学教育、学前教育等师范类专业的大学生，求职中小学教师、教育机构讲师、教研员等实习或校招岗位。内容侧重教学设计与评估能力，适合有教学项目或实习经历、希望突出教育理论与实操结合的求职者。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书
