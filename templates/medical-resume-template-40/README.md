## 模板亮点

- 突出金融理论、编程能力和策略研究闭环
- 适合展示因子挖掘、回测框架和风险指标
- 项目描述强调假设、数据、方法与结论
- 兼顾研究实习、竞赛和课程项目表达

## 适用人群

适合正在准备医院实习/规培申请的用户，尤其适合需要突出教育背景、实习项目、技能证书、校园经历和岗位关键词的人群。

## 包含模块

- 教育背景
- 实习经历
- 项目经历
- 专业技能
- 荣誉证书

## 示例内容摘要

| 模块 | 示例摘要 |
| --- | --- |
| 目标信息 | 医学生求职者 / 2026届临床医学方向求职者 / 示例医科大学 / 临床医学 |
| 教育背景 | 主修临床医学相关课程，完成多门课程设计、项目实践和行业案例分析，围绕医学生求职者方向持续积累专业技能、项目表达和岗位理解。 |
| 实习/工作经历 | 围绕医院实习/规培申请场景参与资料整理、流程推进和结果复盘，协助团队完成需求拆解、信息收集、执行跟进和文档沉淀；结合医学生求职者目标优化表达重点，形成可量化、可追踪的经历成果。 |
| 项目经历 | 构建估值、成长、质量和动量四类因子池，对历史样本进行分层回测和稳定性检验；使用 Python 搭建数据处理与回测脚本，输出年化收益、最大回撤、夏普比率和行业暴露；根据结果提出因子去相关和风格…；整理可转债条款、正股价格和波动率数据，分析转股溢价率、到期收益率和强赎风险；制作风险监控表并撰写研究简报，展示不同市场环境下的资产表现差异。 |
| 技能 | Python、Pandas、NumPy、Statsmodels、SQL、回测框架；因子研究、时间序列、风险指标、研究报告、金融建模 |
| 证书 | CFA Level I 备考、证券从业资格 |
| 荣誉 | 金融建模竞赛校级一等奖；校级一等奖学金 |
| 语言 | 英语 CET-6，能够阅读岗位资料和英文文档。 |
